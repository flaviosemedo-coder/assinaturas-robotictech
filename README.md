# Assinaturas de e-mail da Robotictech

Gerador de assinaturas para Outlook e Gmail. O modelo começa em branco. Nome e cargo são obrigatórios. Telefone e foto são opcionais.

**[Baixar o kit completo (.zip)](https://raw.githubusercontent.com/flaviosemedo-coder/assinaturas-robotictech/main/assinaturas-robotictech.zip)** · [Ver o guia de uma página (PDF)](./01-Leia-primeiro.pdf)

## Como usar

1. Extraia o ZIP e abra no navegador o arquivo do [Outlook](./aplicativo/index.html) ou do [Gmail](./suporte/Gmail.html).
2. Preencha os dados e selecione **Copiar assinatura**.
3. Cole a assinatura nas configurações da conta de e-mail, salve e abra uma nova mensagem para conferir.

O pacote inclui as [notas técnicas da versão 6.1](./02-Guia-tecnico.txt) e o [manifesto de integridade](./SHA256SUMS.txt).
